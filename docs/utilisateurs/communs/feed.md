# Fil d'actualite

## Acceder au feed

Le fil d'actualite est la page d'accueil apres connexion. Il affiche les publications des membres du reseau, triees par pertinence (reactions, commentaires, date de publication).

Les publications sont chargees par page de 10. Faire defiler ou cliquer sur "Voir plus" pour en afficher davantage.

## Reagir a une publication

Cliquer sur l'icone de reaction sous une publication pour exprimer une reaction (j'aime, etc.). Cliquer a nouveau pour retirer la reaction.

## Commenter

Cliquer sur l'icone commentaire ou dans la zone de texte sous une publication. Saisir le commentaire et valider. Il est egalement possible de reagir a un commentaire avec les memes icones.

## Partager une publication

Cliquer sur l'icone de partage. La publication sera partagee sur votre propre fil avec une reference a l'auteur original.

## Sauvegarder une publication

Cliquer sur l'icone de sauvegarde (marque-page) pour conserver une publication dans vos favoris. Cliquer a nouveau pour la retirer.

## Signaler une publication

Si une publication est inappropriee, cliquer sur l'icone de signalement. Le moderateur sera notifie.

## Voir le detail d'une publication

Cliquer sur une publication pour afficher son detail complet : texte, media, reactions et tous les commentaires.

## Publications d'un profil

Sur la fiche d'un membre, un onglet affiche toutes ses publications.
