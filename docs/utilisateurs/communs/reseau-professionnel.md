# Reseau Professionnel

## Acceder au reseau

Le menu "Reseau" ouvre le graphe de reseau professionnel. Il represente les affinites et compatibilites entre les membres.

## Score de compatibilite

Chaque lien entre deux profils est calcule sur 100 base sur :

| Critere | Poids |
|---------|-------|
| Specialites en commun (similarite Jaccard) | jusqu'a 50 pts |
| Parcours academique commun | 20 pts |
| Poste actuel commun | 15 pts |
| Proximite de l'annee de promotion | 15 pts |

## Lire le graphe

Les noeuds representent les membres. Cliquer sur un noeud pour afficher la fiche du membre correspondant.

## Ameliorer son score de reseau

Completer son profil ameliore la qualite du calcul :
- Ajouter ses specialites
- Renseigner son parcours
- Renseigner son poste actuel
- Renseigner son annee de promotion
