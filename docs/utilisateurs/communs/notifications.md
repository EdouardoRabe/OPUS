# Notifications

## Acceder aux notifications

L'icone de cloche dans le menu affiche le nombre de notifications non lues. Cliquer dessus pour ouvrir le panneau de notifications.

## Types de notifications

Les notifications informent des evenements suivants :
- Reaction ou commentaire sur une de vos publications
- Partage de vos publications
- Nouveau evenement cree sur le reseau
- Autres interactions selon votre activite

## Marquer comme lu

- **Une notification** : cliquer sur la notification pour la marquer comme lue.
- **Toutes les notifications** : utiliser le bouton "Tout marquer comme lu" pour vider le compteur d'un coup.

## Historique

Le panneau affiche l'heure relative de chaque notification (a l'instant, il y a X minutes, il y a X heures, il y a X jours).
