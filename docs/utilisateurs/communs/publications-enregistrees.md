# Publications Enregistrees

## Acceder aux publications sauvegardees

Le menu "Publications enregistrees" (ou l'icone marque-page dans la navigation) affiche la liste de toutes les publications que vous avez sauvegardees.

## Sauvegarder une publication

Sur n'importe quelle publication dans le feed, cliquer sur l'icone de sauvegarde (marque-page). La publication est ajoutee a votre liste.

## Retirer une publication sauvegardee

Cliquer a nouveau sur l'icone de sauvegarde sur la publication, ou utiliser le bouton de suppression depuis la page des publications enregistrees.
