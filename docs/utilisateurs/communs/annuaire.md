# Annuaire

## Acceder a l'annuaire

Le menu "Annuaire" ouvre le repertoire des membres du reseau alumni.

## Rechercher un membre

Des filtres sont disponibles pour affiner la recherche :

| Filtre | Description |
|--------|-------------|
| Nom | Recherche par nom ou prenom |
| Promotion | Annee de promotion |
| Parcours | Parcours academique |
| Specialite | Domaine de specialite |
| Entreprise | Employeur actuel |
| Poste | Intitule du poste actuel |
| Annee | Annee de diplome |

Les filtres peuvent etre combines. Les resultats sont pagines (12 par page).

Seuls les profils actifs apparaissent dans les resultats.

## Voir la fiche d'un membre

Cliquer sur un membre dans les resultats pour ouvrir sa fiche complete : informations personnelles, experiences, specialites, reseaux sociaux (selon les parametres de confidentialite de la personne).
