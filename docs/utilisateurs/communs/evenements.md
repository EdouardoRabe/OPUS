# Evenements

## Acceder au calendrier

Le menu "Evenements" ouvre un calendrier interactif affichant tous les evenements du reseau.

- Naviguer entre les mois avec les fleches du calendrier.
- Cliquer sur un evenement pour voir sa fiche detail.

## Voir les evenements en liste

Une vue liste est disponible en complement du calendrier pour parcourir les evenements de maniere lineaire.

## Participer a un evenement

Sur la fiche d'un evenement, cliquer sur "Participer". Le nombre de participants est affiche en temps reel.

## Annuler sa participation

Sur la fiche d'un evenement auquel vous participez, cliquer sur "Annuler la participation".

## Creer un evenement

Cliquer sur "Nouvel evenement" ou sur une date dans le calendrier. Renseigner :
- Titre
- Description
- Date et heure de debut
- Date et heure de fin

Apres creation, l'evenement est visible dans le calendrier. Tous les membres du reseau recoivent une notification.

## Modifier un evenement

Sur la fiche d'un evenement dont vous etes l'auteur, utiliser le bouton de modification pour mettre a jour la description ou les dates.

## Publier un evenement sur le feed

Sur la fiche d'un evenement, cliquer sur "Publier". Cela cree une publication dans le fil d'actualite avec les details de l'evenement. Un evenement ne peut etre publie qu'une seule fois.
