# Mon Profil

## Acceder a son profil

Cliquer sur son nom ou son avatar dans le menu pour ouvrir la page de profil.

## Modifier ses informations personnelles

Dans la section informations, renseigner ou modifier :
- Nom et prenom
- Numero de telephone
- Statut (ex : en poste, en recherche d'emploi)
- Localisation (ville, pays) — utilisee pour apparaitre sur la carte alumni

Valider avec le bouton de sauvegarde.

## Photo de profil

Cliquer sur la photo actuelle ou sur la zone prevue a cet effet. Selectionner une image depuis l'ordinateur. La photo est mise a jour immediatement.

## Curriculum Vitae

- **Deposer un CV** : cliquer sur la zone CV et selectionner un fichier PDF.
- **Supprimer le CV** : utiliser le bouton de suppression a cote du CV existant.

## Experiences professionnelles

Dans la section experiences, cliquer sur "Ajouter une experience" pour renseigner :
- Entreprise
- Poste occupe
- Dates de debut et de fin

Les experiences peuvent etre modifiees ou supprimees individuellement.

## Reseaux sociaux

Ajouter des liens vers vos profils LinkedIn, GitHub, ou autres. Ces liens seront visibles sur votre fiche dans l'annuaire.

## Specialites

Ajouter ou retirer des specialites depuis la liste disponible. Elles sont utilisees pour le calcul du reseau professionnel et les filtres de l'annuaire.

## Confidentialite

Dans les parametres de confidentialite, choisir qui peut voir chaque information du profil (telephone, localisation, experiences, etc.). Chaque champ peut etre rendu visible ou cache independamment.

## Changer de mot de passe

Dans les parametres du compte, saisir l'ancien mot de passe puis le nouveau (deux fois pour confirmation). Valider pour enregistrer.
