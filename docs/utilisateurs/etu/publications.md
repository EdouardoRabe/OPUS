# Creer une Publication (Etudiant)

## Limite quotidienne

En tant qu'etudiant, vous pouvez publier **10 publications maximum par jour**.

## Creer une publication

Cliquer sur le bouton "Nouvelle publication" depuis le fil d'actualite. Renseigner :
- Le texte de la publication
- Le type de publication (partage d'experience, actualite, question, etc.)
- Optionnellement une image ou un fichier joint

Valider pour publier. La publication apparait immediatement dans le fil d'actualite de tous les membres.

## Modifier ou supprimer sa publication

Depuis la fiche de votre publication, les boutons de modification et de suppression sont disponibles. La suppression est definitive cote interface (soft delete en base).

## Quota epuise

Si la limite quotidienne est atteinte, le bouton de creation est desactive jusqu'au lendemain.
