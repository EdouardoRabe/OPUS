# Carte des Alumni

## Acceder a la carte

Le menu "Carte" ouvre une carte interactive affichant la localisation geographique des membres du reseau qui ont renseigne leur localisation.

## Consulter les profils sur la carte

Cliquer sur un marqueur pour afficher la fiche synthetique du membre : nom, photo, promotion, parcours, specialites.

## Apparaitre sur la carte

Pour apparaitre sur la carte, renseigner votre localisation dans votre profil (voir `utilisateurs/communs/profil.md`). Sans localisation, votre profil n'est pas affiche.

Les informations de localisation sont soumises aux parametres de confidentialite de votre profil.
